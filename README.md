# Authentication Application

A simple user authentication application built using **Python and Django**.

## Features

* User Registration
* User Login
* User Logout
* User Authentication

## Technologies

* Python
* Django
* HTML/CSS
* SQLite

## Run the Project

```bash
python manage.py migrate
python manage.py runserver
```

Open in browser:

```text
http://127.0.0.1:8000/
```
